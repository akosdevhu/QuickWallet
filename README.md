QucikWallet - loyalty card wallet 
---------------------------------
Features
- Clean UI  
- Add and manage loyalty cards  
- QR / barcode scanning  
- App association for each card  
- Early implementation of location‑based activation  
- Fast and simple user experience

---------------------------------

Installation
1. Download the APK from the Releases tab.  
2. Install it on your Android device.  
3. Allow the required permissions (camera, location).

---------------------------------

Status
This is an early version (v0.5).  
The project is actively evolving and new features are being added continuously.
